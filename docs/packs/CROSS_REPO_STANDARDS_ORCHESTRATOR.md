# Cross Repo Std Orchestrator

## Purpose

This optional pack provides the user-facing Agent Capability Steward role for governing a standards ecosystem across repositories. It prevents behavior drift while preserving consumer-local authority.

## Included content

- portable Cross Repo Std Orchestrator role;
- Copilot adapter;
- cross-repository orchestration skill and adapter;
- reusable practice-promotion review template.

## Boundaries

The pack governs classification, evidence, release discipline, and adoption process. It does not replace consumer operating manuals, domain safeguards, validation commands, architecture, or branch policy. Standards releases and consumer upgrades are separate reviewed changes.

## Trigger examples

Use for: compare repositories for reusable practices; resolve standards drift; decide core versus optional pack versus overlay; review a real run for promotion; create a standards release; or plan a consumer standards upgrade.
